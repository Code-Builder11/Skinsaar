# Skinsaar — Static UI & Brand Experience Preview

This is a standalone static build of the **Skinsaar ("Skincare ka Naya Sansar")** luxury D2C e-commerce website, prepared for GitHub Pages hosting.

## Included Pages & Features

- **`index.html`**: Complete luxury brand homepage with Announcement Bar, Hero with 15% Vitamin C glow aura card, Bestsellers Grid with discount badges and add-to-bag triggers, Visionary Members 2,000-seat spotlight card, Science & Formulation philosophy pillars, Customer testimonials, and Luxury footer.
- **`products.html`**: Formulations catalog with interactive client-side category filter pills (*Cleansers*, *Serums*, *Creams*, *Sun Protection*), live keyword search, sorting (price / rating), and product cards.
- **`product-detail.html`**: High-conversion product detail page for **Glow Drops** featuring interactive multi-angle image gallery switcher, price breakdown with savings highlight, quantity adjuster, 3 expandable clinical accordions (Key Benefits, Ritual Guide, INCI Formulation), trust signals, sticky mobile bottom bar, and complementary pair recommendations.
- **`visionary.html`**: Exclusive Founding Visionary Members program page with live allocation bar (1,858 / 2,000 remaining), 4 core patronage pillar cards, interactive enrollment form with automated Indian pincode lookup, post-payment modal simulator, and program FAQs.
- **`track-order.html`**: Customer order tracking interface with simulated Bluedart Express live dispatch timeline.
- **Interactive Shopping Bag Drawer (`js/app.js`)**: Slide-over drawer with real-time add/remove/quantity calculations, free shipping threshold indicator (₹699 target), and working promo codes (`WELCOME10`, `SKINSAAR20`, `FLAT150`).

## Hosting on GitHub Pages

1. Push this folder to a GitHub repository:
   
2. In your repository on GitHub:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment**, set Source to **Deploy from a branch**
   - Select branch `main` and folder `/ (root)`
   - Click **Save**
3. Your client preview link will be live at `https://<your-username>.github.io/<your-repo-name>/`
